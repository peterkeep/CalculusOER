Note 10.2.6. Many Representations of One Point.

We’ve seen now that a single point can be represented in many ways!
  1. Polar points \((r,\theta)\) and \((r,\theta + 2k\pi)\text{,}\) where \(k\) is some integer, will end up looking identical.
    🔗
    🔗
  2. Polar points \((r, \theta)\) and \((-r, \theta+(2k+1)\pi)\text{,}\) where \(k\) is some integer, will end up looking identical.
