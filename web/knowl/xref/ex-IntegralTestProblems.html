Exercise 2.

For each of the following series, apply the Integral Test and interpret the conclusion of the test.
🔗

(a)

\(\displaystyle\sum_{k=1}^\infty \left(\frac{k}{k^2+1}\right)\)
🔗
Solution.
\begin{align*} \sum_{k=1}^\infty \left(\frac{k}{k^2+1}\right) \amp \sim \int_{x=1}^\infty \frac{x}{x^2+1}\;dx \\ \amp = \lim_{t\to\infty} \frac{1}{2}\ln(x^2+1)\bigg|_{x=1}^{x=t}\\ \amp = \lim_{t\to\infty} \frac{\ln(t^2+1)}{2} - \frac{\ln(2)}{2}\\ \amp = \infty \end{align*}
The integral diverges, and so the series must diverge as well.
🔗
🔗
🔗

(b)

\(\displaystyle\sum_{k=1}^\infty \left(\frac{k}{e^k}\right)\)
🔗
Solution.
\begin{align*} \sum_{k=1}^\infty \left(\frac{k}{e^k}\right) \amp \sim \int_{x=1}^\infty xe^{-x}\;dx\\ \amp = \lim_{t\to\infty} \left(-xe^{-x} - e^{-x}\right)\bigg|_{x=1}^{x=t}\\ \amp =\lim_{t\to\infty} -\frac{t}{e^t} - \frac{1}{e^t} + \frac{1}{e} + \frac{1}{e}\\ \amp = \frac{2}{e} \end{align*}
The integral converges, and so the series must converge as well.
🔗
🔗
🔗

(c)

\(\displaystyle\sum_{k=2}^\infty \left( \frac{1}{k\ln(k)} \right)\)
🔗
Solution.
\begin{align*} \sum_{k=2}^\infty \left( \frac{1}{k\ln(k)} \amp \sim \int_{x=2}^\infty \frac{1}{x\ln(x)}\;dx\\ \amp = \lim_{t\to\infty} \ln(\ln(x))\bigg|_{x=2}^{x=t}\\ \amp = \lim_{t\to\infty} \ln(\ln(t)) - \ln(\ln(2))\\ \amp = \infty \end{align*}
The integral diverges and so the series diverges as well.
🔗
🔗
🔗

(d)

\(\displaystyle\sum_{k=1}^\infty \left( \frac{k^2+k}{e^k} \right)\)
🔗
Solution.
\begin{align*} \sum_{k=1}^\infty \left( \frac{k^2+k}{e^k} \right) \amp \sim \int_{x=1}^{\infty} (x^2+x)e^{-x}\;dx\\ \amp = \lim_{t\to\infty}\left(-\frac{x^2}{e^x} - \frac{3x}{e^x} - \frac{3}{e^x}\right)\bigg|_{x=1}^{x=t}\\ \amp = \lim_{t\to\infty} - \frac{t^2}{e^t} - \frac{3t}{e^t} - \frac{3}{e^t} + \frac{1}{e} + \frac{3}{e} + \frac{3}{e}\\ \amp = \frac{7}{e} \end{align*}
The integral converges, and so the series converges as well.
🔗
🔗
🔗

(e)

\(\displaystyle\sum_{k=1}^\infty \left( \frac{1}{k^2+1} \right)\)
🔗
Solution.
\begin{align*} \sum_{k=1}^\infty \left( \frac{1}{k^2+1} \right) \amp \sim \int_{x=1}^{\infty} \frac{1}{x^2+1}\;dx\\ \amp = \lim_{t\to\infty} \tan^{-1}(x)\bigg|_{x=1}^{x=t}\\ \amp = \lim_{t\to\infty} \tan^{-1}(t) - \tan^{-1}(1)\\ \amp = \frac{\pi}{2} - \frac{\pi}{4}\\ \amp = \frac{\pi}{4} \end{align*}
The integral converges and so the series converges as well.
