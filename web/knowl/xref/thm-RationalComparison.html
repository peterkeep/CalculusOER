Theorem 8.7.13. Rational Comparison Theorem.

If \(a_k\) is a rational function of \(k\text{,}\) \(a_k = \dfrac{p(k)}{q(k)}\) where \(p(k)\) is a degree \(m\) polynomial function and \(q(k)\) is a degree \(n\) polynomial function, then:
  • If \(n-m \gt 1\text{,}\) then \(\displaystyle\sum_{k=1}^\infty a_k\) converges.
    🔗
    🔗
  • If \(n-m \leq 1\text{,}\) then \(\displaystyle\sum_{k=1}^\infty a_k\) diverges.
