Definition 8.1.3. Recursion Relation.

A sequence is defined using a recursion relation is one where the \(k\)th term of the sequence is defined as a function output of the previous term, the \((k-1)\)st term. The sequence also needs some initial term to base the subsequent terms from.
🔗
Using notation, we might say that \(a_{k} = f(a_{k-1})\text{.}\)
