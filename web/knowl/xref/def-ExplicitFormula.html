Definition 8.1.2. Explicit Formula.

An infinite sequence defined using an explicit formula is one where the \(k\)th term of the sequence is defined as a function output of \(k\text{,}\) the term’s index.
🔗
Using notation, we might say that \(a_k = f(k)\) where:
  • \(a\) is the “name” of the sequence (similar to how \(f\) and \(g\) are common names of functions).
    🔗
    🔗
  • \(k\) is the index of the term, typically a non-negative integer.
    🔗
    🔗
  • \(f(k)\) is the function that we use to generate the terms.
