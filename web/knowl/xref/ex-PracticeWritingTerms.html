Example 8.1.5. Practice Writing some Terms.

For each of the following sequences, write out the first handful of terms. There isn’t a set amount, but you should write out enough to get a feel for the sequence structure and how the different ways of defining the sequences work. In each, you can start the index \(k\) at 1 and count upwards (\(k=1,2,3,...\)).
🔗

(a)

\(a_1 = \frac{1}{3}\) and \(a_k = 2(a_{k-1})^2\)
🔗
🔗

(b)

\(b_k = \frac{\sin(k)}{k^2}\)
🔗
🔗

(c)

\(c_k = \sqrt[k]{k+1}\)
🔗
🔗

(d)

\(d_k = \frac{k + e^k}{e^k}\)
